# jd 多语言反编译框架架构升级计划

## 设计目标
将 jd 从单一 JS 反混淆工具升级为多语言反编译框架，支持数十种场景，全自动识别输入格式并走对应流程。

## 核心架构设计（参考 disrobe）

### 1. Workspace 结构 → 单 crate 多模块

jd 不用 disrobe 的 70 crate workspace（太重），而用单 crate 多模块：

### 2. 核心抽象（core/）

#### Pass + Detector traits
```rust
pub type PassId = &'static str;  // "js.deob", "py.decompile", "native.unpack"

pub trait Pass: Send + Sync {
    fn id(&self) -> PassId;
    fn detector(&self) -> &'static dyn Detector;
    fn output_kind(&self, output: &Artifact) -> OutputKind;
    fn run(&self, artifact: &Artifact) -> Result<Artifact>;
    fn extract_children(&self, input: &Artifact) -> Result<Vec<ChildArtifact>> { Ok(vec![]) }
}

pub trait Detector: Send + Sync {
    fn id(&self) -> PassId;
    fn detect(&self, ctx: &DetectContext) -> Option<DetectVerdict>;
}
```

#### OutputKind（引擎调度核心）
```rust
pub enum OutputKind {
    Source { language: Language, formatted: bool },  // 终端：还原的源码
    Bytes { format_tag: &'static str, family: &'static str },  // 重新入队：下一层 pass 的输入
    Report { format_tag: &'static str, family: &'static str },  // 终端：结构化报告
    Mixed { children: Vec<ChildHandle> },  // 扇出：提取 N 个子文件，各自重新入队
}
```

#### ChainDriver 状态机
- BFS `VecDeque<WorkItem>`，每个 item 含 bytes + depth + history (blake3 去重)
- 每层：detect → pick → run → 按 OutputKind 决定终止/重新入队/扇出
- 深度上限 (cap=8)、循环检测 (blake3 hash set)、累计输出字节预算

#### 自动识别
- 无需用户指定语言/格式
- 每层 PassRegistry::run_all() 遍历所有 detector，返回 DetectVerdict
- 优先级选择：ConfidenceBand → confidence → specificity (低优先) → family precedence
- 高置信度 (>=0.9) 且 specificity<=30 的检测立即短路

### 4. CLI 改造

默认命令 `jd <input>` → `auto` 模式：
- 读取输入文件
- PassRegistry::run_all() 检测格式
- ChainDriver 自动组合 pipeline
- 输出到 -o 或 stdout

保留手动指定：
- `jd js <file>` → 只走 JS pass
- `jd auto <file>` → 全自动（默认）
- `jd identify <file>` → 只识别格式

### 5. 预留的多语言扩展点

每个新语言只需：
1. 创建 `src/passes/<lang>/mod.rs`
2. 实现 `Detector`（magic bytes / 结构检测）
3. 实现 `Pass`（反编译/反混淆逻辑）
4. 在 `passes/mod.rs::build_registry()` 注册

无需修改 core 或 CLI——完全插件式扩展。

### 6. 实施步骤

**Phase 1：架构骨架**（当前）
- 创建 `core/` 模块：Pass/Detector/OutputKind/Registry/ChainDriver
- 将现有 JS 逻辑迁移到 `passes/js/`
- CLI 改为 `auto` 默认
- 保持 393/393 测试通过

**Phase 2：多语言 Pass 预留**
- `passes/python/` — .pyc magic 检测 (占位)
- `passes/native/` — PE/ELF/MachO 检测 (占位)
- `passes/jvm/` — .class/.jar magic 检测 (占位)
- `passes/wasm/` — WASM magic 检测 (占位)

**Phase 3：逐步实现**
- Python .pyc 反编译 (使用 Python dis/marshal 解析)
- Native PE/ELF 解包 (UPX 等)
- JVM .class 反编译
- 更多 JS 混淆器 (JS-Confuser, Jscrambler)
- Bundle 解包 (webpack/vite/browserify)

### 7. 不改的部分
- oxc parser + codegen（JS 解析）
- boa_engine sandbox（JS 沙箱执行）
- clap CLI 骨架
- 现有 obfuscator.io / unminify 逻辑
